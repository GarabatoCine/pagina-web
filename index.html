Si no se ve nada, es porque el navegador está interpretando el "blanco sobre blanco" de una forma que anula el texto antes de aplicar el efecto de transparencia. Para solucionar esto de una vez por todas, vamos a usar una técnica distinta: SVG con Máscara. Es el método más infalible porque no depende de cómo el navegador mezcla colores, sino de una máscara geométrica real. El blanco será blanco y el "agujero" de las letras será real.
